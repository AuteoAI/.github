# Auteo

[Auteo](https://auteo.ai) is an AI creation platform for generating music, video, images, and speech on the web or from your agent.

## Create with Auteo

- **Music:** [Free AI Music Generator](https://auteo.ai/apps/free-ai-music-generator), [AI Song Cover Generator](https://auteo.ai/apps/ai-song-cover-generator), [AI Lyrics Generator](https://auteo.ai/apps/ai-lyrics-generator), and [YuE 2](https://auteo.ai/models/yue2)
- **Video:** [Generate AI video](https://auteo.ai/ai/video)
- **Images:** [Generate AI images](https://auteo.ai/ai-image-generator)
- **Speech:** [Generate AI speech](https://auteo.ai/ai/audio)

## Use Auteo in your agent

- [Auteo Agent Skills](https://github.com/AuteoAI/skills) for music, video, image, and speech workflows
- [Auteo MCP](https://github.com/AuteoAI/auteo-mcp) for remote setup and tool documentation
- [`@auteo/cli` on npm](https://www.npmjs.com/package/@auteo/cli) for terminal use and local stdio MCP
- [Official MCP Registry entry](https://registry.modelcontextprotocol.io/v0.1/servers?search=ai.auteo%2Fauteo) under `ai.auteo/auteo`
- [Auteo MCP setup guide](https://auteo.ai/mcp)
